# 北科電機系學會｜新生入場券 HTML Email 資源庫

本儲存庫託管北科電機系學會「新生入場券」HTML Email 模板與所有高解析度圖片資源（供 GitHub Pages CDN 靜態圖片存取使用）。

---

## 網頁與圖片線上連結 (GitHub Pages)

當此儲存庫開啟 GitHub Pages（Settings -> Pages -> Source: `Deploy from a branch` / `main` / `/ (root)`）後：

- **Email 線上預覽**: [https://ntutee.github.io/freshman_email/](https://ntutee.github.io/freshman_email/)
- **主視覺大合照 (1200 × 650 PX)**: `https://ntutee.github.io/freshman_email/photo_main_1200x650.jpg`
- **活動四宮格拼圖 (1200 × 840 PX)**: `https://ntutee.github.io/freshman_email/activity_collage.jpg`
- **系隊運動雙拼圖 (1200 × 840 PX)**: `https://ntutee.github.io/freshman_email/team_collage.jpg`
